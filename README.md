# Javascript Boilerplate

## Overview

Welcome to the JavaScript Boilerplate! This template serves as a foundation
for building web applications using Vite and SASS with a simple routing system.

## Features

- **Modular JavaScript**: Organized code structure with ES6 modules for better maintainability and scalability.
- **CSS Preprocessing**: Utilizes SASS for styling, allowing for nested rules and variables to keep styles organized.
- **Basic Routing**: Includes a simple routing mechanism to navigate between different pages of the application.

## Getting Started

### Prerequisites

Before you begin, ensure you have the following installed on your machine:

- Node.js (version 20 or higher)
- npm (Node package manager) or Yarn (preferred)

## Project Structure
